# ShareMeal 🍲

ShareMeal is a food donation web application designed to help people share surplus food, connect food donors with people who need food, and reduce food waste.

## 🌐 Live Demo

https://main.dezmqwmma29xb.amplifyapp.com

## ✨ Features

- Home page introducing the ShareMeal platform.
- Donate Food page for submitting food donation details.
- Available Food page for viewing submitted donations.
- AWS Amplify integration for saving and retrieving donation records.
- Responsive web application built with modern web technologies.
- Cloud deployment using AWS Amplify Hosting.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Node.js
- AWS Amplify
- AWS AppSync
- Git and GitHub

## 📄 Application Pages

| Page | Route | Description |
|---|---|---|
| Home | `/` | Introduces the ShareMeal platform |
| Donate Food | `/donate` | Allows users to submit food donation details |
| Available Food | `/food` | Displays available food donations |
